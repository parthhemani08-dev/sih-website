# NIRVANA 🧠⚛️

### AI-Powered Interactive Quantum Learning Platform

NIRVANA is an interactive learning platform designed to make **quantum computing and quantum algorithms easier to explore, experiment with, and understand**.

Built as part of the **Smart India Hackathon 2026** project by **Team RADIOHEADS**, NIRVANA combines interactive visualizations, guided learning, and hands-on experimentation to make abstract quantum concepts more approachable for students and beginners.

> **Explore. Experiment. Understand.**

## 🚀 Live Project

🔗 [NIRVANA — Live Demo](https://nirvana-quantum.vercel.app/)

## ✨ What NIRVANA Offers

- 🧩 Interactive exploration of quantum algorithms
- ⚛️ Visual understanding of quantum concepts
- 🧪 Experimentation with quantum operations and circuits
- 📚 Beginner-friendly learning flow
- 🎯 Designed around learning by doing rather than only reading

## 🛠️ Tech Stack

- **Next.js** — App Router
- **TypeScript**
- **Tailwind CSS**
- **Vercel** — Deployment

## 💻 Run Locally

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd nirvana
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
